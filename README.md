# KN-RAI-Stacje-MecLab
Repozytorium projektu w ramach działalności Koła Naukowego Robotyka Automatyka Informatyka (RAI) na Politechnice Poznańskiej. Przygotowanie cyfrowego bliźniaka oraz wizualizacja procesu na stanowisku firmy MecLab w Node-Red, przygotowanie dokumentacji elektrycznej stanowiska, Połączenie z rzeczywistym stanowiskiem poprzez sterownik s7-1500.
